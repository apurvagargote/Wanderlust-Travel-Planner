 🌍 Wanderlust Travel Planner

A responsive travel planning web application for discovering destinations, exploring local experiences, and organizing trips in one place.

## ✨ Features

- 🗺️ **Destination Explorer** — Discover destinations and famous attractions.
- 📍 **Interactive Map** — Explore destination locations and attractions.
- 🍴 **Food Recommendations** — View local dishes with prices and ratings.
- 🌏 **Local Tips & Culture** — Learn about local customs, culture, and travel tips.
- 📸 **Photo Gallery** — Browse destination photos in a modal gallery.
- 🗓️ **Itinerary Planner** — Organize activities and build trip itineraries.
- 🌤️ **Weather** — Check weather information for destinations.
- 💰 **Budget Planner** — Plan and track travel expenses.
- 💱 **Currency Converter** — Convert currencies for travel budgeting.
- ❤️ **Favorites** — Save and access favorite destinations.
- 📱 **Responsive Design** — Works across desktop and mobile devices.
- 🐳 **Docker Support** — Run the application using Docker and Docker Compose.

 ## 🚀 Getting Started

 ### Clone the Repository

```
git clone https://github.com/apurvagargote/Wanderlust-Travel-Planner.git
```

 ### Navigate to the Project

```
cd Wanderlust-Travel-Planner
```

 ## 🐳 Run with Docker

 Build and start the application:

```
docker compose up -d --build
```

 Open the application:

```
http://localhost:8081
```

 ### Check Container Status

```
docker compose ps
```

 ### View Logs

```
docker compose logs -f
```

 ### Stop the Application

```
docker compose down
```
